# Project Overview

Research and planning repository for implementing faceted search with geospatial awareness and semantic capabilities for location-based datasets.

## Development Setup

- Package manager: npm (default)
- Build: Not applicable (documentation/research repository)
- Test: Not applicable (documentation/research repository)

## Skills Available

This project uses skills for detailed guidance. Load the appropriate skill when working in these areas:

- **progressive-disclosure**: When setting up AGENTS.md, creating skills, managing instruction budget, or optimizing progressive disclosure patterns
- **faceted-search**: When designing or implementing faceted search systems with geospatial and semantic search capabilities

## Critical Conventions

- This is a research/planning repository, not an implementation project
- Skills should follow progressive disclosure best practices (see progressive-disclosure skill)
- Keep AGENTS.md under 150 lines and 150 instructions
- Extract detailed content to skills, reference from AGENTS.md
- Use provided scripts for managing AGENTS.md and skills
